# Samuel Catalano - Portfolio

A scroll-driven voxel London where a red double-decker bus rides through Samuel Catalano's career. Static site (HTML, CSS, JS modules, three.js from CDN), no build step.

- Preview: `python3 -m http.server 8000`
- Tests: `node --test tests/`
- Deploy: push to `main`; GitHub Pages serves from the repo root.

See `CLAUDE.md` and `docs/` for architecture and conventions.
