# Original regional ambient fleet

Ten original Blender-authored traffic assets. No downloaded meshes, photographs, textures, texture UVs or external authoring dependencies. Source geometry is generated by `build_fleet.py`; POC/production exports are byte-identical copies.

## Reproduce

From repository root:

```sh
/opt/homebrew/bin/blender -b --factory-startup --python-exit-code 1 -P tools/vehicles/regional-fleet/build_fleet.py
/opt/homebrew/bin/blender -b --factory-startup --python-exit-code 1 -P tools/vehicles/regional-fleet/render_fleet.py
# Optional contact-sheet composition: use an existing Python with Pillow installed.
python3 tools/vehicles/regional-fleet/render_fleet.py --sheets
```

The builder accepts selected model IDs after `--` for slices. Full builds rewrite `models.json`; slice builds leave its full-fleet manifest intact. Rendering uses Blender EEVEE and the authored files written under `/private/tmp/regional-fleet-pass/asset-evidence/`. Sheet composition uses existing Pillow only; nothing is installed. Blender 5.2.3 LTS was used.

## Contract

Metres; GLB +X forward, +Y up; centered ground origin. Six meshes and exactly one primitive/material per mesh: FleetBody, FleetGlass, FleetTrim, FleetRubber, FleetLights, FleetInterior. Each primitive has POSITION, NORMAL and COLOR_0; backface culling is enabled. All traffic wheels are static and merged. No per-window objects survive export.

Preserve vertex colors when remapping semantic materials: body colors are white for runtime paint multiplication; trim colors distinguish black plastic/chrome/alloy; light colors distinguish headlamps, tail lamps and plate treatments. Glass is closed tinted ambient glazing with a glossy finish; nine common-builder cabins use pierced side sheets and roof screen apertures, with only a narrow seal ring behind each pane. Curved glazing shares the roof/side surface equations. Interior silhouettes are modeled behind the apertures. It is intentionally below the player/cab/bus detail level.

`models.json` gives source body dimensions, measured overall mirror width, exact source wheelbase, exported axle/tyre coordinates and beam anchors in GLB coordinates. Front anchors follow the projected lens centers; the preserved Onix anchors are measured from its production projector bounds. Only bumper overhangs are normalized to the source length, preserving axle centres. Height normalization includes roof rails. Visual axle offsets, tyre/track choices and beam anchors are authored interpretations rather than manufacturer CAD survey data.

## Validation and limits

The builder asserts finite geometry, valid polygon normals and recalculates outward component normals before export. Serialized GLB self-checks cover finite positions, unit normals, material/color contract, triangle/index ranges, exact X/Y bounds, no DoubleSide workaround and POC/production equality. Evidence JSON and seven-view/model diagnostics are written to the temporary evidence directory. Two complete builds are compared by SHA-256 separately.

The initial contact pass exposed planar coachwork and wheel/steering/roof details that needed correction. The final pass rounds the metal envelope before true arch cuts; closes both sides of arch lips; adds lamp housings and generation-specific quarter treatments; removes rear glazing from the panel vans; and puts steering silhouettes behind the screen.

These are stylized ambient interpretations, not licensed CAD replicas. Several modern hatchbacks remain similar in broad form; final recognizability should be judged at the normal game camera. No in-game night/day, loading/disposal or performance claim is made by this asset-only task.
