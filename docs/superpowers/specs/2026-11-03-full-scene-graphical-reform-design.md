# Full-scene graphical reform — design specification

**Status:** Task 1 companion specification, draft for owner review. It records what the baseline captures show and proposes treatments. It does not approve implementation; Tasks 2–6 of the [plan](../plans/2026-11-03-full-scene-graphical-reform.md) implement only the items the owner accepts.

**Baseline:** HEAD `e9225d4` on `feat/site-gamefication`. Only untracked file before this task: the plan itself. Captures and clips: [evidence index](../../evidence/full-scene-graphical-reform/README.md).

## 1. Invariants for every slice

- Map, stops, routes, lot IDs, footprints, heights, landmark anchors and sightlines, walking paths and the HTML career panel are unchanged.
- Placement stays descriptor-driven. Shared materials and geometries, deterministic variation and the existing spatial batching are kept. Architecture stays within the mass / trim / glass buckets.
- No new engine, dependency, paid service or ambiguously licensed asset. Any new asset is recorded in `ASSET_SOURCES.md` first.
- WebGL-off, reduced-motion and 375 px usability are kept (Task 7 checks them).
- Vegetation code and assets belong to the parallel vegetation audit. This spec names them but proposes no change.

## 2. How to read this document

- **Observed** cites an image, crop or clip in the [evidence index](../../evidence/full-scene-graphical-reform/README.md). Nothing is observed from the atlas or from memory.
- **Proposed** is a decision for review, separate from observation.
- **UNKNOWN** means the baseline views do not show the subject. It needs its own capture before any decision.
- **Decision:** KEEP = no change. POLISH = change material, lighting, emissive intensity or surface detail without changing silhouette, footprint or placement. REBUILD = replace geometry; needs a separate gate.
- Scene facts used below were read from code. The atlas's "PCF soft 1024" shadow note is stale: `js/world/scene.js` sets a 2048 map on desktop (lines 68–71) and disables shadows on mobile (line 190).

## 4. Rendering errors observed in the baseline

Each item cites the image that shows it. None of these is a confirmed root cause.

2. **Overexposed Eye pods and rim at night.** [crop](../../evidence/full-scene-graphical-reform/defects/eye-pods-night-overexposure.jpg), [9.5-night](../../evidence/full-scene-graphical-reform/9.5-night.jpg), [rain 9.5-night](../../evidence/full-scene-graphical-reform/rain/9.5-night.jpg).
3. **Emissive outline on the Riverside saw-tooth roof.** [crop](../../evidence/full-scene-graphical-reform/defects/riverside-roof-emissive-outline.jpg), [11-night](../../evidence/full-scene-graphical-reform/11-night.jpg).
4. **Flat elliptical glare pool beside the bus headlight.** Not tied to any lamp; it looks like a projected decal. [crop](../../evidence/full-scene-graphical-reform/defects/glasgow-road-glare-pool.jpg), [11-night](../../evidence/full-scene-graphical-reform/11-night.jpg).
5. **Unmodelled dark underside band on MASP.** A flat panel with no reflection. Not confirmed as z-fighting. [crop](../../evidence/full-scene-graphical-reform/defects/masp-underside-dark-band.jpg), [5-day](../../evidence/full-scene-graphical-reform/5-day.jpg).
6. **Low rim contrast on the Eye in rain.** [rain 9.5-day](../../evidence/full-scene-graphical-reform/rain/9.5-day.jpg).

Checked and not observed in these stills: z-fighting (none in the crops), black glass (none), clipped sun disc (not clipped), texture stretching (none seen), floating objects (none seen at stops 5, 9.5, 11). Not checked: popping, flicker and shadow gaps, which need clips or close-ups.
